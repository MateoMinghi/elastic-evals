# elastic-evals

Open-source observability and evaluation for production AI agents: OpenTelemetry ingestion, OpenSearch as the event store, a cascade of evaluators (deterministic checks → classifiers such as Jev → LLM judges → human review) with calibration, and links to Sentry in both directions.

Status: design phase. Start with [docs/PROPOSAL.md](docs/PROPOSAL.md); background research is in [docs/research/](docs/research/).
